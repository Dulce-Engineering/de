Custom Local Font Options

Option 1: Mea Culpa + Nanum Myeongjo

Captain's Log

Mea Culpa offers an incredibly elegant looping script for headers, reminiscent of old handwritten ship logs. Nanum Myeongjo provides a highly legible, clean serif for all the data and body text readability.

Option 2: Tangerine + Quattrocento

The Storm Glass

Tangerine is a tall, dramatic calligraphy font that screams "pirate treasure map." Quattrocento grounds it with a classic, wide, Roman-style serif that is extremely beautiful and easy to read.

Option 3: Beau Rivage + Charm

The Cargo Manifest

Beau Rivage gives a slightly rougher, ink-and-quill aesthetic for the titles. Charm is a wonderfully unique font—it looks handwritten but retains nearly perfect legibility for paragraphs.
