Introduction

This is a log of the development of Dragechon, a top-down game. The idea is that the player is a flying dragon, as seen from above, and can be controlled by tilting the device. The world spins around the player so the player is always facing forward and up. This game has to run on mobile but dev and debugging is a pain using native code so I'm going to try building it as a browser based game as I have succesfully tested that the tilt mechanism works in a browser. I find Typescript to be incredibly cumbersome, non-standard, verbose, and ineffective so am using Javascript. Am not interested in 3D so am starting simple with 2D. I don't generally like frameworks but the Phaser 3 library seems to be a possible middle ground so will try that.
