# TempusToi

- designed for people that need to know how much time until the next event
- allows you to create alarms for future events
- allows you to create timers for current events
- shows all timers and alarms in chronological order
- shows number of days, hours, minutes, and seconds until an event or timer ends
- triggers audible alarm when an event or timer ends
- whimsical user interface
- no login, email, or credit card details required
- free to use

## Description

TempusToi is a simple and efficient task scheduling tool that helps you stay on top of deadlines. It displays a sorted list of countdown timers, visually representing the time remaining for each task at a glance. Unlike cloud-based planners, TempusToi requires no online account or subscription—it runs entirely on your PC or mobile device, keeping your tasks private and accessible anytime.
