# Porottoz

- designed for people that want to know how much they can spend
- user can set a target date and how much they have to spend
- users can set how much is reserved and not for spending
- app shows how much user can spend per day
- app includes countdown timer to show how much time is left
- user can create multiple budgets
- user can easily adjust balance as purchases are made
- user can easily adjust balance as income is earned
- whimsical user interface
- no login, email, or credit card details required
- free to use
- data stored on your device only
- easy to use
- animated and colourful
