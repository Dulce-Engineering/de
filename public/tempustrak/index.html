A Simpler Human-Centric Approach

Existing time management solutions rely on busy, complicated screens, and require users to create accounts before use. It should'nt be this complicated, especially for individuals or small teams. This is why TempusTrak exists.

TempusTrak allows you to quickly create tasks and immediately start logging your time. Additionally, with a single touch, you can switch between tasks and, when done, you can get summary details by day, week, or month.

  • To create tasks just use the "Add Task" or "Add & Start Task" buttons above.
  • To switch between tasks just click/touch the big round task display.
  • To pause a task click/touch the "Break/Stop" button or the task you want to stop.
  • To edit tasks, delete tasks, view log history, or adjust logged time, click/touch the red menu buttons on each task display.
